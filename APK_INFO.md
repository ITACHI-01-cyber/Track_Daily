## 🚀 How to Upload and Share Your APK

If you have generated an APK for this website and want to share it with users, follow these steps to upload it and make it available for download:

### Option 1: Using Vercel (Easiest - Hosted with your Frontend)
Since your project is already deployed on Vercel, this is the most seamless method:
1. Place your generated `.apk` file in the `public` folder of your React/Vite project (e.g., `public/habit-tracker.apk`).
2. Commit and push the changes to your GitHub repository.
3. Vercel will automatically trigger a new deployment.
4. Your APK will now be accessible at `https://track-daily-git-main-itachi-01-cybers-projects.vercel.app/habit-tracker.apk`.
5. Update the "Download the APK" link above to point to this new URL.

### Option 2: Using GitHub Releases (Best for Version Control)
1. Go to your GitHub repository for the project.
2. On the right side of the repository page, find the "Releases" section and click **"Create a new release"**.
3. Click **"Draft a new release"**.
4. Choose a version tag (e.g., `v1.0.0`) and enter a release title.
5. In the **"Attach binaries by dropping them here or selecting them"** area, drag and drop your `.apk` file.
6. Once the upload is complete, click **"Publish release"**.
7. Right-click the `.apk` file link in the published release, copy the URL, and replace the `#` in the link placeholder above.

### Option 3: Using Google Drive
1. Upload your `.apk` file to Google Drive.
2. Right-click the uploaded file and select **"Share"**.
3. Under "General access", change the setting to **"Anyone with the link"**.
4. Click **"Copy link"**.
5. Paste the link into the "Download the APK" section above.

## 📲 How to Install the APK on Android
Once a user clicks the link to download the APK, they will need to follow these steps to install it:
1. Download the `.apk` file to their Android device.
2. When the download finishes, click **"Open"** on the notification or find the file in the "Downloads" folder.
3. Android may show a security prompt stating: *"For your security, your phone is not allowed to install unknown apps from this source."*
4. Click **"Settings"** on the prompt and toggle on **"Allow from this source"**.
5. Go back and click **"Install"**.
6. Once the installation is complete, click **"Open"** to start tracking habits!
