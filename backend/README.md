# Habit Track Backend

Spring Boot REST API backend for Habit Track application with MongoDB integration.

## Prerequisites

- Java 17 or higher
- Maven 3.6+
- MongoDB 4.0+ (running locally or accessible)

## Project Structure

```
src/main/java/com/habittrack/
├── HabitTrackApplication.java    # Main Spring Boot application
├── config/
│   └── CorsConfig.java           # CORS configuration
├── model/
│   └── Task.java                 # Task entity model
├── repository/
│   └── TaskRepository.java       # MongoDB repository
├── service/
│   └── TaskService.java          # Business logic
└── controller/
    └── TaskController.java       # REST API endpoints
```

## Getting Started

### 1. Ensure MongoDB is Running

```bash
# If using Docker
docker run -d -p 27017:27017 --name mongodb mongo:latest

# Or if MongoDB is installed locally
mongod
```

### 2. Build the Project

```bash
mvn clean build
```

### 3. Run the Application

```bash
mvn spring-boot:run
```

The application will start at `http://localhost:8080`

## API Endpoints

### Tasks

#### Get All Tasks
```
GET /api/tasks
```

#### Get Task by ID
```
GET /api/tasks/{id}
```

#### Create a New Task
```
POST /api/tasks
Content-Type: application/json

{
  "title": "Buy groceries",
  "description": "Buy milk, eggs, and bread",
  "completed": false,
  "priority": "HIGH",
  "dueDate": "2024-12-31T23:59:59"
}
```

#### Update a Task
```
PUT /api/tasks/{id}
Content-Type: application/json

{
  "title": "Updated title",
  "description": "Updated description",
  "completed": true,
  "priority": "MEDIUM",
  "dueDate": "2024-12-31T23:59:59"
}
```

#### Delete a Task
```
DELETE /api/tasks/{id}
```

#### Delete All Tasks
```
DELETE /api/tasks
```

#### Filter Tasks by Completion Status
```
GET /api/tasks/filter/completed?completed=true
```

#### Filter Tasks by Priority
```
GET /api/tasks/filter/priority?priority=HIGH
```

## Configuration

Edit `src/main/resources/application.properties` to customize:

- **MongoDB URI**: Change connection string for remote MongoDB
- **Server Port**: Change default port (8080)
- **Logging Level**: Adjust logging verbosity

## CORS Configuration

The application is configured to accept requests from:
- `http://localhost:5173` (Vite default)
- `http://localhost:3000` (React default)
- `http://localhost:8080`

Modify in `CorsConfig.java` as needed.

## Development

### IDE Setup

1. Open project in your favorite IDE (IntelliJ IDEA, VS Code, etc.)
2. IDE should automatically configure Maven dependencies
3. Run `HabitTrackApplication.java` directly from the IDE

### Hot Reload

Dev tools are included for faster development. Changes to Java files will be automatically recompiled when saved.

## Notes

- MongoDB uses document-based storage, so each task is stored as a separate document
- IDs are auto-generated by MongoDB (ObjectId)
- Timestamps are automatically set for creation and updates
- CORS is configured to allow requests from common development ports
